# yt2obsidian

- `yt2obsidian.py` is the pipeline and the single source of behavior. TUI in `ui.py`. Launcher: `yt`.
- `PRODUCT.md` UI intent, `PRD.md` note format, `FINDINGS.md` open work, `IMPROVEMENTS.md` older archived list.
- Test: `.venv/bin/python test_yt2obsidian.py`
- `run.log` and `config.toml` are private: never print them.
